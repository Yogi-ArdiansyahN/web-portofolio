## Overview
Digital transaction portal for ordering top-up products, with an interface connected to backend services through an API. Users can select a product, enter their details, and monitor order status.

## Problem
Catalog, order submission, and status needed one shared contract between the interface and backend.

## My Contributions
* Built the product catalog interface and the top-up ordering flow on the frontend.
* Consumed the backend API for the product list, order submission, and transaction status.
* Managed form validation and interface state with JavaScript, jQuery, and Tailwind CSS.

## Technical Highlights
An API separates the catalog interface from backend services, with both sides using the same response contract.

## Ringkasan
Portal transaksi digital untuk memesan produk top-up, dengan antarmuka yang terhubung ke layanan backend melalui API. Pengguna dapat memilih produk, mengisi data, dan memantau status pesanan.

## Masalah
