## Business Context
Digital transaction portal for ordering top-up products, with an interface connected to backend services through an API. Users can select a product, enter their details, and monitor order status.

## Role & System Flow
* Built the product catalog interface and the top-up ordering flow on the front end.
* Consumed the backend API for the product list, order submission, and transaction status.
* Managed form validation and interface state with JavaScript, jQuery, and Tailwind CSS.

## Technical Notes
An API separates the catalog interface from the backend services for the product list, order submission, and transaction status. Both sides use the same response contract.

## Konteks Bisnis
Portal transaksi digital untuk memesan produk top-up, dengan interface yang terhubung ke backend services melalui API. Pengguna dapat memilih produk, memasukkan data mereka, dan memantau status pesanan.

## Peran & Alur Sistem
