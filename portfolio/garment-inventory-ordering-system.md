## Business Context
Unifying raw material stock, finished goods, ordering, shipping, returns, and payments in a single internal system for garment operations. The system replaces manual record-keeping and provides an API for sales and partner integrations.

## Role & System Flow
* Converted the master and payment tables from client-side processing to server-side DataTables with newest-first sorting and efficient search.
* Improved the partner API flow by removing N+1 queries through fetching transactions at once and grouping them by type and reference.
* Handled reverts and reapplication of changes when API fixes needed adjustment.
* I used AI-assisted coding for the query refactor and tests, then made the optimization decisions myself.

## Technical Notes
Server-side DataTables replaced client-side processing for the master and payment tables, with newest-first sorting and search on the server. I removed N+1 queries in the partner API by fetching transactions once and grouping them by type and reference.
