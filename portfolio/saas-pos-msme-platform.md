## Overview
SaaS POS platform for MSMEs to manage sales and reporting for one or multiple branches. Owners can monitor transactions and sales summaries from a single interface.

## Problem
Branch data had to stay consistent from cashier input through to sales summaries.

## My Contributions
* Built the cashier transaction flow through to sales reports accessible by business owners.
* Prepared a responsive admin interface with Bootstrap and jQuery for transaction input and branch monitoring.
* Managed the MySQL schema and client-side integration.

## Technical Highlights
The data flow runs from cashier transaction to sales report, with MySQL schema and client-side integration keeping branch data consistent.

## Ringkasan
Platform POS berbasis SaaS untuk UMKM mengelola penjualan dan pelaporan satu atau banyak cabang. Pemilik dapat memantau transaksi dan ringkasan penjualan dari satu antarmuka.

## Masalah
Data cabang harus tetap konsisten mulai dari input kasir hingga ringkasan penjualan.

## Kontribusi Saya
* Membangun alur transaksi kasir hingga laporan penjualan yang dapat diakses pemilik usaha.
* Menyiapkan antarmuka admin responsif dengan Bootstrap dan jQuery untuk input transaksi dan pemantauan cabang.
* Mengelola skema MySQL dan integrasi sisi klien.

## Sorotan Teknis
Alur data berjalan dari transaksi kasir hingga laporan penjualan, dengan skema MySQL dan integrasi sisi klien yang menjaga konsistensi data cabang.
