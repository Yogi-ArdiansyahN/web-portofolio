## Business Context
A SaaS-based POS platform to help MSMEs manage sales and reporting, whether for a business with one branch or multiple branches. Owners can monitor transactions and sales summaries from a single interface.

## Role & System Flow
* Built the cashier transaction flow through to sales reports that business owners can access.
* Prepared a responsive admin interface with Bootstrap and jQuery for transaction input and branch monitoring.
* Managed the MySQL schema and client-side integration to keep cross-branch data consistent.

## Technical Notes
The data flow runs from cashier transaction to sales report. I managed the MySQL schema and client-side integration so branch data stays consistent in the summary.
