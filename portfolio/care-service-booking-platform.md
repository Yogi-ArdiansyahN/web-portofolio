## Overview
Connects families with home caregivers through search, booking, payment, and service reviews. The system consists of a customer portal, an operations console, and a mobile app for caregivers to manage schedules and earnings.

## Problem
A static service list and layout changes around the visual refresh made the booking flow harder to maintain.

## My Contributions
* Built the booking flow from service search and caregiver selection through saved booking sessions, payment confirmation, and reviews.
* Replaced the static service list with a dynamic dropdown from the database and added a trust section before the service catalog.
* Tidied up responsive CSS and components so the visual identity update did not disrupt the booking flow.

## Technical Highlights
Component cleanup and manual review of responsive changes kept the booking flow intact during the visual refresh.

## Ringkasan
Menghubungkan keluarga dengan perawat rumahan melalui pencarian, pemesanan, pembayaran, dan ulasan layanan. Sistem terdiri dari portal pelanggan, konsol operasional, dan aplikasi seluler bagi perawat untuk mengelola jadwal serta pendapatan.

## Masalah
Daftar layanan statis dan perubahan tata letak saat penyegaran visual membuat alur pemesanan lebih sulit dipelihara.

## Kontribusi Saya
* Membangun alur pemesanan dari pencarian layanan dan pemilihan perawat hingga sesi pemesanan tersimpan, konfirmasi pembayaran, dan ulasan.
* Mengganti daftar layanan statis dengan dropdown dinamis dari basis data dan menambahkan bagian kepercayaan sebelum katalog layanan.
* Merapikan CSS responsif dan komponen agar pembaruan identitas visual tidak mengganggu alur pemesanan.

## Sorotan Teknis
Pembersihan komponen dan tinjauan manual terhadap perubahan responsif menjaga alur pemesanan tetap berjalan saat identitas visual diperbarui.
