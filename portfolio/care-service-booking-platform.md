## Business Context
Connects families with home caregivers through search, booking, payment, and service reviews. The system consists of a customer portal, an operations console, and a mobile app for caregivers to manage schedules and earnings.

## Role & System Flow
* Built the booking flow from service search and caregiver selection through saving booking sessions, payment confirmation, and reviews.
* Replaced the static service list with a dynamic dropdown from the database and added a trust section before the service catalog.
* Tidied up responsive CSS and components so the new visual identity did not disrupt the booking flow.
* I used AI-assisted coding for CSS iteration and layout fixes, then reviewed the booking flow manually.

## Technical Notes
CSS and component cleanup kept the booking flow intact during the visual identity change. I reviewed the flow manually after the layout fixes.
