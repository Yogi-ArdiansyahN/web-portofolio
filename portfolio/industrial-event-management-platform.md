## Overview
Handles registration and publication of industrial conference content. Admins can manage articles, categories, and events without relying on developers for day-to-day content changes.

## Problem
Admins needed to manage articles, categories, and events without developer involvement for daily content changes.

## My Contributions
* Designed article and category CRUD with automatic slugs, server-side search and pagination, and related articles based on tags.
* Implemented the media pipeline from editor uploads and type and size validation to WebP conversion and application storage.
* Adjusted the responsive layout and deployment flow so content changes remained stable.

## Technical Highlights
The media pipeline validates uploads, converts them to WebP, and stores them in application storage. Data structure and upload flow were verified directly.

## Ringkasan
Menangani pendaftaran dan publikasi konten konferensi industri. Admin dapat mengelola artikel, kategori, dan acara tanpa bergantung pada pengembang untuk perubahan konten harian.

## Masalah
Admin perlu mengelola artikel, kategori, dan acara tanpa keterlibatan pengembang untuk perubahan konten sehari-hari.

## Kontribusi Saya
* Merancang CRUD artikel dan kategori dengan slug otomatis, pencarian dan halaman di server, serta artikel terkait berdasarkan tag.
* Menerapkan alur media dari unggahan editor dan validasi jenis serta ukuran berkas hingga konversi WebP dan penyimpanan aplikasi.
* Menyesuaikan tata letak responsif dan alur deploy agar perubahan konten tetap stabil.

## Sorotan Teknis
Alur media memvalidasi unggahan, mengonversi berkas ke WebP, dan menyimpannya di penyimpanan aplikasi. Struktur data dan alur unggah diverifikasi langsung.
