## Business Context
Handles registration and publication of industrial conference content independently. Admins can manage articles, categories, and events without relying on developers for day-to-day content changes.

## Role & System Flow
* Designed article and category CRUD flows with automatic slugs, server-side search and pagination, and related articles based on tags.
* Implemented the media pipeline from editor uploads, type and size validation, and WebP conversion to saving in application storage.
* Adjusted the responsive layout and deployment flow so content changes remained stable.
* I used AI-assisted coding for the layout iteration, then verified the data structure and upload flow manually.

## Technical Notes
The media pipeline validates uploads, converts them to WebP, and stores them in application storage. I verified the data structure and upload flow while adjusting the responsive layout and deployment flow.
