## Overview
Helps clinicians manage treatment cases, medical records, and patient communication in a single workflow. The system covers record status changes, notifications, and data synchronization between the web frontend and the API.

## Problem
Record status changes and conversation events must stay aligned between the web frontend and the API.

## My Contributions
* Implemented the medical record flow from analysis results to draft, then a transition to final through a signature endpoint with optimistic cache updates in the frontend.
* Designed the care conversation flow with presence indicators, message receipts, and close and reopen controls.
* Maintained frontend and API synchronization when record status and conversation flows changed.

## Technical Highlights
Optimistic cache updates keep frontend and API state aligned when record status or conversation state changes. Status and signature validation were reviewed directly while maintaining tests and serializers.

## Ringkasan
Membantu tenaga klinis mengelola kasus perawatan, rekam medis, dan komunikasi pasien dalam satu alur kerja. Sistem mencakup perubahan status rekam, notifikasi, dan sinkronisasi data antara frontend web dan API.

## Masalah
Perubahan status rekam dan percakapan harus tetap selaras antara frontend web dan API.

## Kontribusi Saya
* Menerapkan alur rekam medis dari hasil analisis menjadi draft, lalu transisi menjadi final melalui endpoint tanda tangan dengan optimistic cache updates di frontend.
* Merancang alur percakapan perawatan dengan indikator kehadiran, tanda terima pesan, serta kontrol tutup dan buka kembali.
* Menjaga sinkronisasi frontend dan API saat status rekam dan alur percakapan berubah.

Optimistic cache updates menjaga state frontend dan API tetap selaras saat status rekam atau percakapan berubah. Validasi status dan tanda tangan ditinjau langsung sambil menjaga pengujian dan serializer.
